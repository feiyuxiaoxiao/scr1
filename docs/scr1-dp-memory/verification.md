# SCR1 双端口存储器验证文档（Verification）

- 被测模块：`scr1_dp_memory`（`src/top/scr1_dp_memory.sv`，111 行）
- 验证目标：双端口读写、字节使能、两种实现一致性

---

## 1. 功能检查项（Feature Checklist）

| ID | 功能点 | 依据行号 | 检查方法 |
|---|---|---|---|
| FC-DPM-1 | 端口 A 同步读 | `:85-89`/`:64-66` | `rena` 后一拍取数 |
| FC-DPM-2 | 端口 B 同步读 | `:94-105`/`:59` | `renb` 后取数 |
| FC-DPM-3 | 字节使能写（Intel） | `:43-58` | `webb` 单/多字节 |
| FC-DPM-4 | 字节使能写（通用） | `:96-101` | `webb` 单/多字节 |
| FC-DPM-5 | `wenb=0` 不写 | `:45`/`:95` | 写使能关闭 |
| FC-DPM-6 | 双端口独立地址 | `:19`/`:25` | 不同地址并发 |

---

## 2. 覆盖建议

| 场景 | 说明 |
|---|---|
| 单字节写 | 逐字节 `webb` |
| 多字节写 | 任意 `webb` 组合 |
| 读改写 | 端口 B 同地址读后写 |
| 双口并发 | A 读 + B 写不同地址 |
| 实现对照 | Intel 与通用分支功能等价 |

---

## 3. 断言

本模块无 SVA。

---

## 4. 验证结论

存储器行为为标准同步 RAM 模型，通过定向读写与字节使能覆盖即可；Intel/通用分支
应做功能等价性检查。
