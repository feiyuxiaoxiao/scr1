## 2. 覆盖建议

| 场景 | 说明 |
|---|---|
| 指令连续取指 | 背靠背 `imem_req` 保持 `RDY_OK` |
| 数据读三宽度 | BYTE/HWORD/WORD 回对齐 |
| 数据写三宽度 | 字节选通正确 |
| 指令/数据并发 | 双端口同时访问不同地址 |
| 空闲 | 无请求时 `resp=NOTRDY` |

## 3. 断言

本模块无 SVA。

---

## 4. 验证结论

TCM 覆盖单拍访问、读写并发与字节偏移处理；正确性依赖 `scr1_dp_memory` 与集成回归。
