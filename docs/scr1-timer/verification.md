## 2. 覆盖建议

| 场景 | 说明 |
|---|---|
| 自由计数 | `en=1`、`div=0` |
| 分频计数 | `div>0`，脉冲周期验证 |
| RTC 计数 | `clksrc_rtc=1`，跨时钟域脉冲 |
| 比较中断 | `mtime` 跨越 `mtimecmp` |
| 写 cmp 清/刷新 | 中断置位后写 cmp |
| 非法访问 | 半字/非对齐/越界偏移 |
| 高低字写 | 保持另一半不变 |

## 3. 断言

本模块无 SVA。

## 4. 验证结论

定时器覆盖寄存器访问、计数/分频、RTC 同步与中断语义；非对齐与越界访问返回错误响应。
